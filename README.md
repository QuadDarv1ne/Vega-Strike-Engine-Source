Открытый космический симулятор, позволяющий игроку **исследовать, торговать и сражаться** в огромных просторах космоса. Вы начинаете на старом потрёпанном грузовом корабле, с бесконечными возможностями впереди и ровно столько денег, чтобы с трудом свести концы с концами. Но в космосе за пределами скрывается опасность.

Он **достаточно лёгкий, достаточно стабильный и достаточно живой**, чтобы в него хотелось возвращаться.

## Почему Vega Strike

Космических симуляторов уже достаточно. Vega Strike не хочет быть ещё одной оболочкой с «более длинным списком функций», а собирает в себе всё, что делает космос живым и настоящим:

| Что для вас действительно важно | Как это делает Vega Strike |
| --- | --- |
| **Живая вселенная** | Вселенная полностью динамична и развивается сама по себе, независимо от прогресса игрока. Эпические битвы происходят во множестве систем без вашего участия. |
| **Корабли и оружие** | Никогда прежде не виданные корабли, смоделированные командой Vegastrike; разнообразное оружие на разных звёздных кораблях; болтовые орудия со светящимися эффектами освещения. |
| **Масштаб и свобода** | Несколько систем, включая весь сектор Sol и сектор Vega; огромные многослойные поля астероидов; туманности, где ваш радар сходит с ума. |
| **Тактика и манёвры** | Сжатие времени, маскировка (частичная или полная невидимость), щиты, светящиеся при попадании, нормальная сила, отбрасывающая корабли друг от друга, взрывы, буквально разрывающие корабль на куски. |
| **Продвинутая физика** | BSP-деревья позволяют подлетать близко к звёздному кораблю и находиться на взлётной полосе правильно построенных моделей; быстрая система столкновений без проблем. |
| **Настраиваемость** | Полностью рабочий HUD с дисплеями наведения; настраиваемые логотипы инопланетных рас; настраиваемые миссии; интеллектуальный, программируемый ИИ. |
| **Звук и атмосфера** | Потрясающий саундтрек; звуковые эффекты, от которых звёздные корабли ревут, пролетая мимо, и издают звук «зап», когда погибают; звёзды, пролетающие мимо, пока вы исследуете систему. |
| **Управление** | Полноценная поддержка джойстика; возрождение клавишей ';'; переключение кораблей клавишей '['; все классические раскладки управления. |

> Вселенная вращается вокруг вас, а не вы вокруг YAML.

## Что он умеет

- **Космические полёты и бой**: полностью рабочий HUD, разнообразное оружие, ракеты, турели, щиты и маскировка.
- **Торговля и исследование**: множество систем, станции, планеты, астероидные поля и туманности.
- **Динамическая вселенная**: мир развивается сам по себе, независимо от действий игрока.
- **Прыжки между системами**: варп-двигатель (прыжок через зелёные точки), SPEC-двигатель для сверхсветового перемещения внутри системы.
- **Множество кораблей**: разнообразные модели от команды Vegastrike и сообщества.
- **Программируемый ИИ**: полностью скриптуемый искусственный интеллект с настраиваемыми поведениями.
- **Настраиваемые миссии**: создавайте свои миссии на XML и делитесь ими с сообществом.
- **Кастомизация HUD и логотипов**: изменение внешнего вида под себя.
- **Кинематографичные взрывы**: разрывающие корабль на куски.
- **Сжатие времени**: долгие перелёты без скуки.
- **Модификация и взлом**: возможность менять сохранения, корабли и игровые параметры.
- **Сообщество и поддержка**: активные форумы, Gitter, списки рассылки.

## 🖥 Поддержка платформ

| Платформа            | Статус   |
| --------------- | ------ |
| Windows         | ✅ Поддерживается (установщики для Windows 10 и 11, начиная с v0.9.0-beta1) |
| Linux           | ✅ Поддерживается |
| macOS Intel (x86_64) | ✅ Поддерживается (официально только macOS 13) |
| macOS Apple Silicon | ❌ Официально не поддерживается (нужна помощь сообщества) |

> Vega Strike всё ещё активно разрабатывается; перед обновлением сохраняйте резервные копии важных файлов конфигурации.

### Windows требует Python 3.12.10

Если вы устанавливаете Vega Strike версии **0.11.0** в Windows, вам также нужно отдельно установить **Python 3.12.10**, чтобы игра работала. Требуется именно эта версия Python. Без неё игра молча завершится сразу после запуска.

Скачать можно здесь: <https://www.python.org/downloads/release/python-31210/>

(В будущем, возможно, мы найдём лучший способ обработки зависимости от Python.)

## 📥 Скачивание и запуск

Либо установите Vega Strike с помощью бинарного установщика для вашей платформы, если он доступен, либо следуйте инструкциям по сборке из исходного кода.

- Сначала измените настройки с помощью `bin/vegasettings`
- Затем запустите `bin/vegastrike-engine`

### Параметры командной строки

```man
  vegastrike-engine -ddata_dir [-px,y,z] [-jsector/starsystem] missionname

ОПЦИИ
  -d/my/data/dir
    указывает /my/data/dir как путь для поиска данных vega strike.
    Обязателен.

  -p1024,2405,1245090101
    Принудительно задаёт начальное местоположение игрока как
    x=1024, y=2405, z=1245090101

  -jgemini_sector/troy
    Принудительно задаёт игроку старт в системе troy сектора gemini.

  missionname
    Указывает миссию, которую должен запустить vegastrike.
    По умолчанию main_menu.mission.
